About this project

Raw Smith Circle is the production loyalty platform of Raw Smith Specialty Coffee in Amman. This application is Phase 3 of a three-phase course project for 606315 Programming for Data Science.

Phase 1 · Foundations

NumPy operations and a Pandas exploratory data analysis across five anonymized tables (transactions, customers, rewards, redemptions, menu), surfacing the core loyalty metrics and customer behaviour patterns.

Phase 2 · Enrichment

A multithreaded CSV loader, the Open-Meteo weather API (261 days of Amman weather merged by date), and ICO Arabica coffee prices (nine months merged by month), producing a single enriched dataset of 1,000 transactions across 19 columns.

Phase 3 · Product (this app)

A Django web application with template inheritance and clean URL routing, a Chart.js analytics dashboard powered by the Django ORM, two scikit-learn models (a tier classifier and a daily-volume regressor) served from serialized joblib pipelines, a Django REST Framework API, and a cloud deployment on Render.
